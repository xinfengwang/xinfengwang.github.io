Agent 开发全生命周期

以企业政策问答为例，先约定答案必须可核对，再构建检索和生成链路。上线后发现的失败要能对应到一个待修复环节，并回到评估集。

{% include engineering-cover.html image='lifecycle' alt='' %}
  1. 需求分析明确谁在什么情境下使用系统，以及什么算任务完成。
  2. 场景定义列出可回答的问题、可访问的数据和需要升级人工处理的情况。
  3. 架构设计划分模型决策、程序校验、数据权限和人工授权的责任。
  4. 核心能力建设分别验证工具、检索、记忆和上下文组装，确定模块契约。
  5. 工作流编排定义任务状态、分支、循环反馈与停止条件。
  6. 系统实现实现模型和工具适配、持久化、并发、幂等及回执。
  7. 评估与安全用代表性任务验证结果、权限和故障恢复，记录已知边界。
  8. 部署上线按版本逐步放量，配置运行监控、回滚路径和容量限制。
  9. 监控与迭代根据线上轨迹找到最早的错误，把修复验证写进回归集。
