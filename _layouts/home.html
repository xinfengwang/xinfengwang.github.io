AI Agent 开发：从需求到上线

一个 Agent 从接到任务到交付结果，中间到底要写什么？这个博客从第一次工具调用讲起，接着写模型该拿到哪些资料、工作流怎么保存进度、任务中断后怎么继续，以及上线前要测哪些失败场景。

你现在做到哪一步了？

刚开始写第一个 Agent

先拿一个有明确交付物的任务练手。接上一个只读工具，跑通从提问到返回带出处的答案。

  1. 写清任务和验收条件
  2. 让模型发起第一次工具调用
  3. 动手做一个文档 Agent

原型能跑，多步任务容易出错

把检索结果、当前步骤和已完成的动作存下来，看看失败后能不能接着做。

  1. 搜到了，证据在哪一步丢了？
  2. 用状态机串起多步任务
  3. 写入成功却没收到回执，怎么恢复？

准备交给别人用

先测权限、超时和失败用例。改了模型或工作流之后，用同一批任务检查结果有没有退步。

  1. 决定哪些动作需要人工确认
  2. 总完成率没变，为什么要回滚？
  3. 把一次漏检索变成上线门禁
