# Wang Xinfeng's Blog

Jekyll / GitHub Pages 技术博客。

新增或修改文章后，执行 `python scripts/build_connections.py` 更新真实反向引用和带理由的相关推荐，并一同提交 `_data/connections.json`。脚本仅使用 Python 标准库。

术语定义见 `_data/glossary.json`，系列复盘见 `_data/series_reviews.json`，固定版本的项目资料见 `_data/project_evidence.json`。项目资料卡表示查阅来源，不表示本轮测试通过。反馈状态在读者展开后主动加载自公开 GitHub Issues；关闭不会自动标为已修订。

深度教程写作见[文章规范](scripts/engineering-writing.md)和[可复用文章模板](scripts/templates/engineering-article.md)。专题的已有内容、缺口、问答状态与建设顺序见[知识覆盖清单](scripts/engineering-content-map.md)。
